# ScholarMind: Historical Review Patterns

*This ledger tracks recurring methodological, structural, and logical flaws across reviewed manuscripts. The ScholarMind orchestrator consults this file to identify if an author is repeating past mistakes.*

## Tracked Anti-Patterns

### 1. The "Post-Hoc Narrative"
- **Description:** Adjusting the hypothesis in the abstract/introduction to match the results, rather than testing the original stated hypothesis.
- **Reviewer Trigger:** Prof. Factcheck and Dr. Rigor.
- **Historical Occurrences:** 0

### 2. The "Over-Promising Abstract"
- **Description:** The abstract claims broad, generalized impacts, but the methodology reveals a highly restricted, niche sample size (n < 30).
- **Reviewer Trigger:** Ms. Clarity and Dr. Rigor.
- **Historical Occurrences:** 0

### 3. The "Self-Citation Loop"
- **Description:** Using the author's own previous, non-peer-reviewed pre-prints to justify foundational methodological choices to bypass actual evidentiary support.
- **Reviewer Trigger:** Prof. Factcheck.
- **Historical Occurrences:** 0
